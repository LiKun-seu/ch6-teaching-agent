# 题库自测与错题本验收

对应远端 issue #1。业务入口 `/self-test`，组件导出 `SelfTestView`；直接挂载 `<SelfTestView />` 即可，不需要 AI Drawer、聊天、笔记或模型 Provider。现有侧栏最终由课堂线程接入，本分支不修改 AppShell、Sidebar、依赖或锁文件。

## 数据与首版边界

- 全部 150 题都有难度和逐题标注理由；简单 47、中等 79、困难 24。当前结构有效且不预填答案的可抽题为 **91**，不是 issue 基础统计中的 115；见 [难度及缺损说明](question-difficulty.md)。保留原题导入备注中的必要纠正和适用条件，例如 SC-66 与 SC-51。
- 题型、难度各维度内并集，两维交集；先过滤再 Fisher–Yates 洗牌无放回抽样。5/10/20/30 快捷题量和自定义正整数，不足不跨条件补题。
- 两个独立 localStorage key：`ch6-self-test-v1` 保存最近会话的题目快照、顺序、答案、当前题和结果；`ch6-wrongbook-v1` 保存错题及已处理场次 ID。没有 80 条截断，也不读取、写入或迁移笔记 key。
- 读取失败禁写并提示重试；并发读取重试共用同一请求。写失败保留内存、串行写入并显示未保存状态。旧写入成功不能清除新版本的未保存标记。
- 仅 `grade() === false` 自动记错。空白、待核对、答错分开，答对的错题重练不自动移出。同场重复交卷、刷新结果、移出后重新加载旧结果均不重复累计。
- 最近提交尚未应用到错题本，或错题写入尚未完成时，不能开始新卷替换最近结果。修复读取或写入并重试后可继续，避免存储异常时丢失待收录证据。
- 错题重练明确使用保存的题目版本，不悄悄换成最新题库。再次答错更新最近错误快照及累计次数。全量/勾选导出使用错题记录快照；本次自测导出使用本场结果快照，即便已手动移出错题本仍能导出本场错误。
- 三模板为对照纠错、空白重练、简洁复习。范围与最近10/20/全部独立可选，按最近答错时间倒序。空范围禁导出。空白模板的数据和可见内容都不含标准答案、解析、个人作答。
- 浏览器打印 / 另存为 PDF 与 Markdown 文件下载均不调用模型或 `/api/digest`。打印使用现有 Markdown/KaTeX、等待字体与图片加载、标题避免跨页、图片自适应和长公式宽度收缩。文件名、正文含日期、模板、范围与题数。

## 手工产品验收步骤

1. 桌面和手机打开 `/self-test`；切换题型/难度，确认可用题数变化。清空任一维度、输入0/负数/小数/超额，确认提示和禁止开始；超额点「改为 N 题」只调整题量。
2. 选择、判断、填空各作答，使用上一题/下一题/进度编号/定位未答。刷新后仍是同一试卷、相同顺序与答案。交卷前无标准答案与解析；未答交卷可以取消回到作答。
3. 结果显示总题、四种状态、完成率和有定义分母的正确率。每题显示我的答案、标准答案、解析；无解析如实提示。刷新结果不重复收录错题。
4. 错题按题型和难度筛选、勾选、重练保存版本。答错累计次数加1，答对仍保留，手动移出后刷新不再出现。笔记页面原数据继续可用。
5. 三种范围与三模板，逐一下载 Markdown；文件名日期和题数正确。空白重练搜索「标准答案」「解析」「我的错误答案」应不存在。本次结果导出不依赖移出后的错题记录。
6. 打印 / 另存为 PDF 打开浏览器打印预览，检查中文、公式、选项、长题分页；允许弹窗后正常打开，阻止弹窗有明确提示。预览中的空白重练没有答案。
7. 用浏览器故障注入/禁用存储复现读取和写入失败。读取错误时不得新数据覆盖旧key；保存错误显示未保存，操作后的数据仍在内存，释放空间后点重试。错题本未持久化前尝试新卷应明确阻止，最近结果仍在。

浏览器截图、打印预览和三平台检查的最终证据在 PR 与 CI artifacts 中记录；这份文档不把未运行的人工检查写成通过。
